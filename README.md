# One line to make the judge fall in love

This is a program that writes one short text for make.fun's bounty `u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13`: a single line, at most 240 characters, meant to make the judge fall for a person, a place, a machine or an idea. `main.py` holds that line as one string constant and writes it, UTF-8 and without a trailing newline, into the folder named by `MAKEFUN_OUTPUT_DIR` when that is set and `/output` otherwise, creating the folder and printing the character count to stderr.

```text

```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
